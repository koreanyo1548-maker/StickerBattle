# 그림 규격 (교체용 레퍼런스)

모든 그림은 `assets/art/이름.webp`에 있고, 소스에서 `"@art:이름"`으로 참조한다(`src/content/art.js`).
**교체할 때는 파일 이름, 캔버스 크기, 기준점을 그대로 지키고 파일만 바꾼 뒤 `node tools/build.mjs`로 다시 빌드한다.**
좌표는 모두 그림 캔버스의 픽셀 좌표(왼쪽 위가 0,0)다.

공통 화풍: 굵은 짙은 갈색 외곽선(#2c1c17 근처), 단순한 평면 셀 음영, 귀여운 판타지 스티커. 배경은 완전 투명(배경 그림 제외).

## 새로 추가한 그림 (임시 그림, 교체 대상)

`tools/make-placeholder-art.mjs`가 도형으로 그린 임시 그림이다. 가이드 이미지는 `docs/art-guides/`.

### 블라인드 몬스터 4종

| 파일 | 대상 |
|---|---|
| `monster_fire.webp` | 불꽃 슬라임 (불 블라인드) |
| `monster_water.webp` | 물결 슬라임 (물 블라인드) |
| `monster_lightning.webp` | 번개 슬라임 (번개 블라인드) |
| `monster_boss.webp` | 슬라임 왕 (4번째 보스 블라인드, 속성은 런마다 무작위라 세 속성 문양을 모두 가짐) |

| 항목 | 값 |
|---|---|
| 캔버스 | 1254 × 1254, 투명 배경 |
| 기준점 | **(627, 1165)** = 바닥 중앙. 발(몸 아래쪽)이 바닥선 y=1165에 닿게 |
| 안전 영역 | x 127~1127, y 115~1165 (1000 × 1050). 뿔·불꽃 등 돌출부도 이 안에 |
| 좌우 중심 | x = 627 |
| 화면 표시 | 88 × 88 CSS px 상자(세로 760px 이하 화면은 68 × 68). 캔버스 전체를 `contain`으로 담으므로 바닥선이 상자 아래에서 7% 위에 온다. 상자 아래 18%~82% 폭에 그림자 타원이 깔린다 |
| 연출 | 대기 중 살짝 흔들림(`idle`), 목표 달성 시 납작해지며 사라짐(`defeat`) |
| 코드 위치 | `src/content/art.js` 몬스터 줄(`pivot:{x:627,y:1165}`), `src/content/data.js` `monsters`, 화면 `blindZone()` |

가이드: `docs/art-guides/monster-guide.png` (빨강 점선 = 캔버스, 파랑 점선 = 안전 영역, 초록 = 바닥선·중심선·기준점).
캐릭터 그림과 같은 바닥선·중심선을 쓴다. 캐릭터 옆에 세워도 발 높이가 맞는다.

### 보상 카드 뒷면

| 항목 | 값 |
|---|---|
| 파일 | `reward_back.webp` |
| 캔버스 | 600 × 840 (5:7), 투명 배경. 바깥 테두리는 가장자리에서 10px 안쪽, 모서리 반지름 약 38 |
| 안전 영역 | 48, 48 ~ 552, 792 (504 × 744). 중요한 문양은 이 안에 |
| 화면 표시 | 보상 화면 카드 폭 30%(최대 약 108 CSS px), 비율 5:7로 채움. 카드 앞면·뒷면이 같은 크기라 뒤집을 때 크기가 변하지 않음 |
| 주의 | 세 장이 모두 같은 그림이어야 섞기가 공정하다. 등급·종류를 드러내는 표시를 넣지 말 것 |
| 코드 위치 | `src/content/art.js` `asset_reward_back`, 화면 `rewardCards()` |

가이드: `docs/art-guides/reward-back-guide.png`.

### 그림 없이 CSS로 만든 것
보상 카드 앞면과 등급 테두리(하: 기본, 중: 은색 이중 테두리, 상: 금색 배경과 빛), 레벨 배지, 목표 게이지. 나중에 그림으로 바꾸려면 `src/styles.css`의 `.rfront`, `.g-mid`, `.g-high`를 대체한다.

| 별 등급 장식 `rank_badge`, `rank_warrior`/`rank_archer`/`rank_mage`, `rank_crest` | 1254 × 1254 | 위치·크기는 `art.js`의 `rankPose`. 별 Lv1 이상 배지, Lv3 이상 어깨 장식, Lv5 이상 후면 문장 |
