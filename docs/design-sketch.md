# 설계 스케치: 블라인드 구조 개편

목표: 크레이지게임즈 베이직 런치. 핵심은 도파민과 직관적인 플레이.
상태: 아이디어 스케치. 현재 `index.html`에는 아직 반영하지 않았다.

## 1. 런 구조

| 항목 | 값 |
|---|---|
| 블라인드 | 4개. 4번째는 보스 |
| 턴 | 블라인드당 6턴. 6턴이 끝나면 전투(목표 점수 판정) |
| 핸드 / 붙이기 | 5장 / 턴당 3회. 캐릭터 배치도 붙이기 1회 |
| 원정대 | 최대 3명. 블라인드가 바뀌어도 유지 |
| 캐릭터 카드 | 블라인드 1은 1~3턴 확정, 블라인드 2~4는 1턴 확정, 그 외 턴은 랜덤 |
| 실패 | 목표 점수 미달이면 런 즉시 종료. 메타 성장 후 재도전하는 루프 |

## 2. 적(블라인드)

- 적은 원정대가 아니라 **목표 점수 하나**. 몬스터 1체로 표시하고 목표 점수 = 체력.
- 블라인드마다 **속성 1개**. 상성 판정 대상.
- **다음 블라인드 속성은 미리 공개**하고, 불리한 캐릭터에는 경고 아이콘을 띄운다.
- 보스는 규칙 하나를 비튼다 (예: 별 레벨 절반, 번개 봉인).
- 적 원정대 AI와 종족·무기 상성은 제거한다.

## 3. 성장 라인

점수 = (기초 + 무기 + 족보) × 조합 무기 배율 × 상성 배율

| 라인 | 올리는 방법 | 효과 | 위치 |
|---|---|---|---|
| 별 Lv | 별 스티커를 붙임. 상한 없음 | 해당 캐릭터 기초 +고정값 | 기초 (파랑) |
| 속성 Lv | 같은 속성을 붙임. 상한 없음 | 블라인드 상대 상성 배율 | 배율 (빨강) |
| 조합 무기 Lv | 블라인드 사이 보상으로만 | 조합 무기 효과 | 배율 (빨강) |

### 별
- 붙일 때마다 Lv+1. 해당 캐릭터의 기초 점수가 고정값만큼 오른다.
- 별 족보: 페어(2명 같은 Lv), 트리플(3명 같은 Lv), 스트레이트(3명 연속 Lv). Lv0은 판정에서 제외.
- 별 족보 보너스는 **레벨 비례**. 기본값은 다른 족보보다 낮게 시작.
- 몰빵(한 명의 기초 극대화)과 분산(족보)이 경쟁하는 구조.

### 속성
- 같은 속성을 붙이면 Lv+1. **다른 속성을 붙이면 교체되고 Lv1부터 다시 시작.**
- 상성은 **대칭(공평)**: 유리 ×(1 + k·Lv), 불리 ÷(1 + k·Lv), 무관 ×1. 곱셈 대칭이라 점수가 0이 되지 않는다.
- 불리 위험이 있으므로 **속성은 별 족보보다 강력해야 한다.**
- 3명에게 서로 다른 속성을 붙이면 위험이 분산되고, 속성 컬렉션 족보와도 맞물린다.
- 순환: 불 > 번개 > 물 > 불.

### 조합 무기 (화염검 등 9종)
- 무기 + 속성으로 결정. 런 안에서 **규칙을 바꾸는 유일한 층** (발라트로의 조커 역할).
- 레벨은 **레시피 단위로 저장** ("화염검 Lv3"은 누가 들든 적용). 속성을 바꿔 레시피가 바뀌어도 키운 레벨은 남는다.
- 속성 Lv은 조합 무기에 영향을 주지 않는다.
- 상대 기준 효과는 다시 정의: 역류검 "상대보다 낮으면 +15" → 예: "목표 점수의 절반 미만이면 ×2".
- 보상 카드에는 "조건 충족 중" 표시.

### 기타 족보 (종족·직업·무기·속성)
- 페어/컬렉션/트리플 유지.
- 보너스에 **블라인드 단계 배수** 적용. 보상 풀에 **족보 레벨업**을 섞는다.

### 같은 무기 중첩
- 지금은 구현하지 않는다(거절). 나중에 쌍검, 대궁, 강화 지팡이를 레시피 한 줄로 추가할 수 있게 붙이기 규칙을 데이터로 판정한다.

## 4. 블라인드 사이 보상 (택1)

3개 중 하나를 고른다. 새 규칙을 만들지 않고 있는 것을 키운다.
- 보유한 조합 무기 Lv+1 (없으면 조합 재료 스티커)
- 족보 레벨업
- 특수 스티커 (홀로그램 등, 메타에서 해금)

덱에 넣기/빼기는 폐지. 덱은 고정(현재 18장).

## 5. 메타 성장 (다음 단계)

- 런이 끝나면 다음 런의 난이도 단계가 오르고, 메타 성장을 가져간다.
- 스티커 뽑기: 캐릭터·조합 무기·특수 스티커 해금 위주(폭). 중복은 작은 시작 레벨 보너스(힘).
- 첫 런은 결과와 상관없이 봉투 1개 지급.
- 즉시 실패 규칙이므로, 실패해도 도달한 단계에 비례해 재화를 준다.

## 6. 시뮬레이션 (`tools/sim-balance.mjs`)

`node tools/sim-balance.mjs [판수]`, 수치는 `SIM='{"키":값}'`로 덮어쓴다.
단순화: 조합 무기는 조건 없이 ×(1.5 + 0.5·(Lv−1)), 보스 규칙 없음, 보상은 조합 무기 Lv+1만.
플레이어 모델: greedy(매 행동마다 현재 블라인드 점수가 가장 높은 선택), random.

기본 수치 2000판 결과 (greedy, 블라인드별 최종 점수 중앙값): 547 / 1434 / 3335 / 7525. 블라인드당 약 2.3~2.6배 성장.
random은 같은 구간에서 85 / 239 / 574 / 1238. 실력 차이가 점수에 크게 반영된다.

요소별 영향 (블라인드 4 중앙값, 1000판):

| 제거한 요소 | 중앙값 | 변화 |
|---|---|---|
| 없음 (기본) | 7609 | — |
| 속성 상성 | 5088 | −33%, 상위 10%는 27839 → 9406 |
| 별 족보 | 7425 | −2% |
| 조합 무기 레벨 | 3606 | −53% |

- 속성이 별 족보보다 강하다는 원칙은 충족. 상위권 점수 폭발의 주원인이 속성.
- **별 족보는 거의 영향이 없다.** 몰빵 대 분산 고민이 생기려면 올려야 한다. pair 4 / straight 8 / triple 12(× Lv)로 올리면 중앙값이 약 +5% 오른다.
- 조합 무기 레벨(보상)이 가장 큰 성장원. 보상 선택이 중요한 결정이 된다.

목표 점수 후보 300 / 900 / 2200 / 5000의 누적 클리어율:
- greedy: 98% / 90% / 69% / 48%
- random: 1% / 0% / 0% / 0%

greedy는 다음 블라인드를 고려하지 않는 근시안 모델이고, 실제 사람의 실력 분포는 모른다. 목표 점수는 플레이테스트로 다시 맞춘다.
