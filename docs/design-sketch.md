# 설계 스케치: 블라인드 구조 개편

목표: 크레이지게임즈 베이직 런치. 핵심은 도파민과 직관적인 플레이.
상태: 아이디어 스케치. 현재 `index.html`에는 아직 반영하지 않았다.

## 1. 런 구조

| 항목 | 값 |
|---|---|
| 블라인드 | 4개. 4번째는 보스 |
| 턴 | 블라인드당 6턴. 6턴이 끝나면 전투(목표 점수 판정) |
| 핸드 / 붙이기 | 5장 / 턴당 3회. 캐릭터 배치도 붙이기 1회 |
| 원정대 | 최대 3명. 블라인드가 바뀌어도 유지 |
| 캐릭터 카드 | 블라인드 1은 1~3턴 확정, 블라인드 2~4는 1턴 확정, 그 외 턴은 랜덤 |
| 실패 | 목표 점수 미달이면 런 즉시 종료. 메타 성장 후 재도전하는 루프 |

## 2. 적(블라인드)

- 적은 원정대가 아니라 **목표 점수 하나**. 몬스터 1체로 표시하고 목표 점수 = 체력.
- 블라인드마다 **속성 1개**. 상성 판정 대상.
- **다음 블라인드 속성은 미리 공개**하고, 불리한 캐릭터에는 경고 아이콘을 띄운다.
- 보스는 규칙 하나를 비튼다 (예: 별 레벨 절반, 번개 봉인).
- 적 원정대 AI와 종족·무기 상성은 제거한다.

## 3. 성장 라인

점수 = (기초 + 무기 + 족보) × 조합 무기 배율 × 상성 배율

| 라인 | 올리는 방법 | 효과 | 위치 |
|---|---|---|---|
| 별 Lv | 별 스티커를 붙임. 상한 없음 | 해당 캐릭터 기초 +고정값 | 기초 (파랑) |
| 속성 Lv | 같은 속성을 붙임. 상한 없음 | 블라인드 상대 상성 배율 | 배율 (빨강) |
| 조합 무기 Lv | 블라인드 사이 보상으로만 | 조합 무기 효과 | 배율 (빨강) |

### 별
- 붙일 때마다 Lv+1. 해당 캐릭터의 기초 점수가 고정값만큼 오른다.
- 별 족보: 페어(2명 같은 Lv), 트리플(3명 같은 Lv), 스트레이트(3명 연속 Lv). Lv0은 판정에서 제외.
- 별 족보 보너스는 **레벨 비례**. 기본값은 다른 족보보다 낮게 시작.
- 몰빵(한 명의 기초 극대화)과 분산(족보)이 경쟁하는 구조.

### 속성
- 같은 속성을 붙이면 Lv+1. **다른 속성을 붙이면 교체되고 Lv1부터 다시 시작.**
- 상성은 **대칭(공평)**: 유리 ×(1 + k·Lv), 불리 ÷(1 + k·Lv), 무관 ×1. 곱셈 대칭이라 점수가 0이 되지 않는다.
- 불리 위험이 있으므로 **속성은 별 족보보다 강력해야 한다.**
- 3명에게 서로 다른 속성을 붙이면 위험이 분산되고, 속성 컬렉션 족보와도 맞물린다.
- 순환: 불 > 번개 > 물 > 불.

### 조합 무기 (화염검 등 9종)
- 무기 + 속성으로 결정. 런 안에서 **규칙을 바꾸는 유일한 층** (발라트로의 조커 역할).
- 레벨은 **레시피 단위로 저장** ("화염검 Lv3"은 누가 들든 적용). 속성을 바꿔 레시피가 바뀌어도 키운 레벨은 남는다.
- 속성 Lv은 조합 무기에 영향을 주지 않는다.
- 상대 기준 효과는 다시 정의: 역류검 "상대보다 낮으면 +15" → 예: "목표 점수의 절반 미만이면 ×2".
- 보상 카드에는 "조건 충족 중" 표시.

### 기타 족보 (종족·직업·무기·속성)
- 페어/컬렉션/트리플 유지.
- 블라인드 단계에 따른 자동 배수는 **폐지**. 성장은 보상의 족보 레벨업(플레이어 선택)으로만.

### 족보 레벨업 (블라인드 사이 보상)
- 레벨은 **족보 종류 단위** 3개: 페어 / 컬렉션 / 트리플. 5축 전체에 공통 적용.
- 별 족보도 같은 레벨을 따른다: 별 페어 → 페어, 별 스트레이트 → 컬렉션, 별 트리플 → 트리플.
- 레벨 효과 (시뮬레이션 후보값):
  - 보너스 점수 ×(1 + (Lv−1))
  - **성립한 족보마다 배율 ×(1 + 0.25·(Lv−1))**. 여러 축에서 같은 족보가 성립하면 배율이 여러 번 곱해진다.
- 덧셈(보너스)만 올리면 성장이 거의 없다. 배율을 함께 올려야 점수 폭발이 생긴다.
- 결과적으로 "페어 빌드", "트리플 빌드", "컬렉션(분산) 빌드" 같은 빌드 정체성이 생긴다.

### 같은 무기 중첩
- 지금은 구현하지 않는다(거절). 나중에 쌍검, 대궁, 강화 지팡이를 레시피 한 줄로 추가할 수 있게 붙이기 규칙을 데이터로 판정한다.

## 4. 블라인드 사이 보상 (야바위 뽑기)

- 진행: **보상 카드 3장을 앞면으로 공개 → 뒤집기 → 섞기 → 1장 선택**. 고른 카드가 보상.
- 섞은 뒤 고른 카드는 **실제로 추적한 그 카드**여야 한다(결과를 몰래 바꾸지 않음). 추적에 성공하면 원하는 걸 받는 미니게임.
- 섞기 난이도(교체 횟수·속도)로 운과 실력의 비율을 조절한다. 목표: 원하는 카드 추적 성공률 약 40~50%. 플레이테스트로 조정.
- 선택 후 나머지 2장은 다시 공개하지 않는다.
- 새 규칙을 만들지 않고 있는 것을 키운다.
  - 보유한 조합 무기 Lv+
  - 족보 레벨업 (페어 / 컬렉션 / 트리플)
  - 특수 스티커 (홀로그램 등)
- **등급**: 같은 효과에 하 / 중 / 상. 예: 페어 Lv +1 / +2 / +3. 초안 확률 하 60% / 중 30% / 상 10%.
  - 상 카드가 3장 중에 보이면 "저걸 잡아라"라는 기대가 생긴다. 앞면 테두리와 빛으로 등급을 구분하고, 뒷면은 모두 같게.
  - 평균 레벨 상승이 1 → 1.5가 되므로 목표 점수를 다시 맞춰야 한다.
- 덱에 넣기/빼기는 폐지. 스티커 덱은 고정(현재 18장).
- **메타 연결(예정)**: 보상 카드 3장은 "보상 덱"에서 뽑는다. 메타 성장으로 보상 덱을 구성(카드 추가, 등급 상향)한다.

## 5. 메타 성장 (다음 단계)

- 런이 끝나면 다음 런의 난이도 단계가 오르고, 메타 성장을 가져간다.
- 스티커 뽑기: 캐릭터·조합 무기·특수 스티커 해금 위주(폭). 중복은 작은 시작 레벨 보너스(힘).
- 첫 런은 결과와 상관없이 봉투 1개 지급.
- 즉시 실패 규칙이므로, 실패해도 도달한 단계에 비례해 재화를 준다.

## 6. 시뮬레이션 (`tools/sim-balance.mjs`)

`node tools/sim-balance.mjs [판수]`, 수치는 `SIM='{"키":값}'`로 덮어쓴다.
단순화: 조합 무기는 조건 없이 ×(1.5 + 0.5·(Lv−1)), 보스 규칙 없음.
보상은 보유 조합 무기 Lv+1과 족보 레벨업 3종 중 무작위 3장, 그중 1장을 무작위로 받음(`rewardPick: 'blind'`).
플레이어 모델: greedy(매 행동마다 현재 블라인드 점수가 가장 높은 선택, 보상은 다음 블라인드 기준), random.
greedy는 앞을 내다보지 않는 모델이고 실제 사람의 실력 분포는 모른다. 목표 점수는 플레이테스트로 다시 맞춘다.

### 1차: 블라인드 자동 배수(1/2/4/8)가 있을 때
- 후반 성장의 대부분을 자동 배수가 만들었다. 빼면 블라인드 4 중앙값이 7866 → 3000.
- 별 족보는 3배, 10배로 올려도 +7%, +13%. 자동 배수를 받는 다른 족보에 묻혔다.
- → 자동 배수 폐지.

### 2차: 자동 배수 제거, 별 족보 3배 (3/6/9)
greedy 중앙값 580 / 1205 / 2025 / 3000. 성장률 ×2.1 → ×1.7 → ×1.5로 **점점 둔화**.

| 제거한 요소 | 블라인드 4 중앙값 | 변화 |
|---|---|---|
| 없음 | 3000 | — |
| 속성 상성 | 2100 | −30% |
| 별 족보 | 2718 | −9% |
| 조합 무기 레벨 | 1292 | −57% |

### 3차: 족보 레벨업 보상 추가 (보고 고르는 방식으로 측정)
| 족보 레벨업 효과 | greedy 중앙값 (블라인드 1~4) | 보상 선택 비율 (조합 무기 / 페어 / 컬렉션 / 트리플) |
|---|---|---|
| 보너스 점수만 ×Lv | 580 / 1188 / 2016 / 3027 | 82% / 2% / 1% / 15% |
| + 배율 ×(1+0.25·(Lv−1)) | **580 / 1916 / 4176 / 8420** | 32% / 33% / 12% / 23% |
| + 배율 ×(1+0.5·(Lv−1)) | 580 / 3545 / 9796 / 26325 | 22% / 40% / 14% / 24% |

- 보너스 점수만 올리면 사실상 선택되지 않는다.
- 배율 0.25가 후보. 성장률 ×3.3 → ×2.2 → ×2.0으로 후반까지 폭발이 유지되고, 보상 선택이 네 갈래로 고르게 나뉜다.
- 0.5는 폭주한다 (블라인드 4 상위 10%가 10만 이상).
- 페어가 가장 자주 성립해서 가장 많이 선택된다. 족보별로 배율 증가폭을 다르게 할지 검토 (예: 페어 0.15 / 컬렉션 0.3 / 트리플 0.4).

배율 0.25 기준, 목표 300 / 900 / 2200 / 5000의 누적 클리어율:
- greedy: 98% / 87% / 69% / 52%
- random: 1단계부터 약 1%

### 4차: 뒤집기 뽑기 (무작위 보상), 배율 0.25
| 보상 방식 | greedy 중앙값 (블라인드 1~4) | 누적 클리어율 (300/900/2200/5000) |
|---|---|---|
| 보고 고름 (비교용) | 573 / 1910 / 4129 / 8613 | 98 / 85 / 68 / 52% |
| **뒤집기 (무작위)** | 573 / 1640 / 3333 / 6214 | 98 / 83 / 63 / 43% |

- 무작위라서 블라인드 4 중앙값이 28% 낮아지고 운에 따른 편차가 커진다. 성장률은 ×2.9 → ×2.0 → ×1.9로 폭발은 유지.
- 받은 보상의 약 13%는 받는 순간 효과가 없다 (예: 트리플이 없는데 트리플 레벨업). 나중에 쓸모가 생길 수는 있다.
- 3000판 기준. 보상 등장 비율: 조합 무기 41%, 족보 레벨업 각 19~21%.

### 5차: 야바위 뽑기 + 등급 (하 60% +1 / 중 30% +2 / 상 10% +3)
플레이어 모델: greedy는 다음 블라인드 기준으로 가장 이득인 카드를 노리고, 45% 확률로 추적에 성공한다. 실패하면 나머지 2장 중 하나.
random은 3장 중 무작위. 3000판.

| 방식 | greedy 중앙값 (블라인드 1~4) | 블라인드 4 p10 ~ p90 |
|---|---|---|
| 등급 없음, 무작위 | 573 / 1633 / 3426 / 6172 | 2378 ~ 18131 |
| 등급, 무작위 | 573 / 2042 / 5131 / 11895 | 3125 ~ 51437 |
| **등급, 추적 45%** | 573 / 2076 / 5581 / **13506** | 3560 ~ 61069 |
| 등급, 항상 성공 (비교용) | 573 / 2673 / 9010 / 23940 | 5072 ~ 121641 |

- 등급이 들어가면 블라인드 4 중앙값이 약 2.2배. 상위 10%는 6만을 넘어 "대박" 구간이 생긴다.
- 추적 45%는 무작위보다 +14%. 운이 주도하고 눈썰미가 조금 보탠다. 추적 성공률을 올리면 실력 비중이 커진다 (100%면 2배).
- 편차가 크다 (블라인드 4 p90/p10 약 17배). 즉시 실패 규칙과 합쳐지면 운이 나쁜 런은 일찍 끝난다.

목표 점수 후보 (기본 난이도), greedy 누적 클리어율:

| 목표 (블라인드 1~4) | 클리어율 |
|---|---|
| 300 / 900 / 2200 / 5000 | 98 / 88 / 76 / 66% |
| 300 / 1000 / 2800 / 7000 | 98 / 84 / 68 / 54% |
| **300 / 1100 / 3000 / 8000** | **98 / 80 / 63 / 49%** |
| 300 / 1200 / 3500 / 10000 | 98 / 77 / 56 / 40% |
| 400 / 1100 / 2800 / 6500 | 87 / 71 / 58 / 47% |

- 블라인드 1은 목표를 조금만 올려도 클리어율이 크게 떨어진다 (300 → 400에서 98% → 87%). 첫 블라인드는 거의 확실히 넘게 300으로 고정.
- 기본 난이도 후보: **300 / 1100 / 3000 / 8000**. greedy가 절반쯤 런을 완주. 사람은 greedy보다 약할 수도, 앞을 내다봐서 더 강할 수도 있으니 플레이테스트로 재조정.
- random은 어느 곡선에서도 블라인드 1을 거의 못 넘긴다.

## 7. 남은 결정

- 별 족보 기본값 (현재 3/6/9 × 별 Lv)
- 보상 풀 구성과 등장 가중치, 빈 보상 완화 방법
- 섞기 난이도 (추적 성공률)와 블라인드별 변화
- 메타 난이도 단계별 목표 점수 배율
- 보스 규칙 목록
- 조합 무기 9종의 새 효과 문구 (상대 기준 효과 재정의)
- 수치 부풀리기 단위 (×10 등)
